# AI Agent v0.1 Documentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove external-product framing, make AI-agent source commentary English, and publish an accurate v0.1 feature guide.

**Architecture:** `init-v2.org` remains the only authored source for `lisp/init-ai.el` and `site-lisp/omy-ai.el`; comments are translated there and regenerated with Org Babel. The existing design and plan remain technical records with neutral language, while `docs/ai-agent-v0.1.md` becomes the user-facing reference for implemented behavior.

**Tech Stack:** Emacs Lisp, Org Babel tangle, gptel, gptel-agent, Minuet, ERT.

## Global Constraints

- Change only documentation and AI-agent branch-owned source commentary.
- Keep `omy-ai` symbols, paths, environment variables, backend endpoints, model names, and model prompt payloads unchanged.
- Preserve `lisp/init-WeaveX.el` and all non-AI configuration.
- Do not hand-edit `lisp/init-ai.el` or `site-lisp/omy-ai.el`; regenerate both from `init-v2.org`.
- The v0.1 guide may describe only currently implemented behavior.
